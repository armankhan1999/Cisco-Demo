## CSM-SPECIFIC METRICS DEFINITIONS

### Portfolio Health Score

**Formula:**
```
Portfolio Health = Weighted Average of All Account Health Scores
Weight = Account ARR / Total Portfolio ARR
```

**Interpretation:**
- 90-100: Thriving portfolio
- 75-89: Healthy portfolio
- 60-74: Attention needed
- <60: Significant intervention required

---

### Touch Cadence Compliance

**Formula:**
```
Compliance % = (Accounts Touched Per Policy / Total Accounts) × 100%
```

**Policy by Tier:**
- Strategic: Weekly minimum
- Enterprise: Bi-weekly minimum
- Commercial: Monthly minimum
- SMB: Quarterly minimum

**Target:** >95% compliance

---

### On-Time Renewal Rate

**Formula:**
```
On-Time Rate = (Renewals Completed Before Expiration / Total Renewals) × 100%
```

**Benchmarks:**
- Excellent: >95%
- Good: 90-95%
- Fair: 85-90%
- Poor: <85%

---

### Expansion Success Rate

**Formula:**
```
Success Rate = (Expansion Opportunities Closed-Won / Total Expansion Opportunities) × 100%
```

**Benchmarks:**
- World Class: >40%
- Good: 30-40%
- Average: 20-30%
- Needs Improvement: <20%

---

### Feature Adoption Velocity

**Formula:**
```
Velocity = (Features Adopted This Period - Features Adopted Last Period) / Days in Period
```

**Healthy Velocity:**
- Onboarding (0-90 days): 2-3 features/month
- Growth (90-180 days): 1-2 features/month
- Mature (180+ days): 0.5-1 features/month

---

### Customer Effort Score (CES)

**Measurement:** Post-interaction survey (1-7 scale)

**Question:** "How easy was it to interact with our team?"

**Scoring:**
- 7 = Very Easy
- 4-6 = Moderate Effort
- 1-3 = High Effort

**Target:** Average >6.0

## ALERTS & NOTIFICATIONS FOR CSM PERSONA

### Critical Alerts (Immediate Action Required)

| Alert | Trigger Condition | Recommended Action |
|-------|------------------|-------------------|
| Health Score Crash | >20 point drop in 7 days | Immediate customer call |
| Renewal Risk | <30 days to renewal + health <60 | Executive escalation, save plan |
| Executive Disengagement | No exec contact in 180 days + renewal <90 days | Executive re-engagement campaign |
| Usage Collapse | >50% utilization drop in 30 days | Technical health check |
| Negative NPS | Detractor score (0-6) received | Immediate follow-up call |
| Support Escalation | P0/P1 ticket opened | Proactive outreach |

### Warning Flags (Monitor Closely)

| Flag | Trigger Condition | Recommended Action |
|------|------------------|-------------------|
| Stagnant Adoption | No new features in 90 days + mature customer | Enablement session |
| Touch Cadence Miss | Missed 2 consecutive scheduled touches | Re-engage |
| Champion Departure | Key stakeholder left company | Relationship rebuilding |
| Low Engagement | Declining meeting acceptance rate | Adjust approach |
| Product Underutilization | <50% utilization for 60+ days | Training campaign |

## APPENDIX: CSM-SPECIFIC USE CASES

### Use Case 1: Monday Morning Portfolio Review
**Scenario:** Start of week, CSM needs to prioritize accounts  
**Dashboard Action:** Tab 1 → View health changes → Check action priority queue  
**Outcome:** Clear prioritized list of accounts needing attention

### Use Case 2: Renewal Preparation (60 Days Out)
**Scenario:** Upcoming renewal, need to prepare proposal  
**Dashboard Action:** Tab 5 → Select account → Tab 2 → Review usage → Tab 4 → Check expansion opportunities  
**Outcome:** Data-driven renewal strategy with expansion recommendations

### Use Case 3: QBR Preparation
**Scenario:** Quarterly business review with customer in 2 days  
**Dashboard Action:** Account deep-dive → Usage trends → Feature adoption → Health components → Export to PDF  
**Outcome:** Professional QBR deck with usage analytics

### Use Case 4: At-Risk Account Intervention
**Scenario:** Health score dropped 25 points  
**Dashboard Action:** Tab 1 → Drill into health components → Tab 2 → Check usage drop → Tab 3 → Review engagement gaps  
**Outcome:** Root cause identification and action plan

**Scenario:** Customer mentioned interest in additional products  
**Dashboard Action:** Tab 4 → View white-space → Check ICP fit → Review peer benchmarks → Tab 1 → Confirm health
